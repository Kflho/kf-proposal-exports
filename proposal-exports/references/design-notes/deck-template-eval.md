# 评审：按模板出片的审美效果（taste-skill 口径）

> 对象：`dev/tpl-demo/`（16:9 模板，主题色 NAVY/AMBER，标题黑体、正文宋体）
> → `demo-out.pptx` 3 页（2 页套版式 + 1 页复制页）。
> 方法：先跑机械项（`deck_check`、`deck_spec`），再按 taste-skill 的 house rules / 法条逐条看渲染图
> （层级、一个主张、对齐、留白、反模板、字体分工），最后给分与改法。

## 逐条评（taste-skill 法条）

| 法条 | 观察 | 判定 |
| --- | --- | --- |
| 一页一个主导 | 48pt 标题独占上方，正文三条；无抢戏元素 | ✅ |
| 层级（两三档做可见工作） | 标题 44 / 正文 20，约 2.2 倍；能看出层级，但跳跃偏保守 | ⚠️ 建议标题 40、正文 24 或加一条"结论带" |
| 对齐 | 标题居中、正文左对齐：两条轴线不一致 | ⚠️ 模板默认；要统一就让标题左对齐（或正文与标题同左边距） |
| 留白 | 三条要点的页面下半约 45% 空；不属于"一次有意的留白" | ⚠️ 正文提到 24pt，或补一条来源/结论带 |
| 反模板 | 无图标卡、无 pill、无渐变、无 01/02 编号 | ✅ |
| 字体分工 | 修复前：`a:ea` 写 `SimHei` 被静默回退，标题与正文同为宋体，层级只剩字号 | ✅ 已修（见下） |
| 色彩预算 | 强调色只出现在标题色/表头，未泛滥 | ✅ |

## 本轮修掉的真问题

**中文字体名必须用中文族名。** 页片 run 里写 `a:ea="SimHei"` / `"SimSun"`，在这台机器的 Office
里不解析，PowerPoint 静默回退到宋体——标题黑体等于没有，层级只剩字号差。同一条渲染实测：
`黑体` / `宋体` 生效，`SimHei` / `SimSun` 全部回退。已把 `deck_fonts.py` 默认、`deck_gate`
的角色检查、模板主题字体全部改成中文族名，并回归了 `test_fonts`。

## 两条待办（模板侧，不是工具侧）

1. 若模板标题居中，正文也与标题对齐或把标题改左对齐——否则两条轴线永远打架；
2. 三点以下的页，模板给的正文档位偏小，建议在 plan 里把 body 字号提一档（或模板加"结论带"占位符）。
