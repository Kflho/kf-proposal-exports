# 指标表述规范（图与正文必须逐字一致）

> 指标是验收依据。写上图的每一个数字，都要能被追问三件事：**谁考核、怎么测、跟谁比**。

## 1. 指标名

- 用**任务书/指南原文的名称**，不自造。原文本身不合规范时（如"定位测距"这种生造词），
  **先按原文写**，同时在台账记一条："指南原文记法 XXX，是否规范化待项目组确认"。
- 一旦项目组同意规范化，**图、正文、技术方案、台账四处同时改**，并在台账留下原文备查。
- 例：`≤10 m@1 km` → `1 km 处定位精度 ≤10 m`（距离限定前置，符合 3GPP/ITU 记法）。

## 2. 五类指标的写法模板

| 类型 | 模板 | 例 |
| --- | --- | --- |
| 绝对量指标 | `名称 ≥/≤ 数值 单位` | `通感专用定位测距（组网模式） ≥10 km` |
| 精度类 | `距离/条件 处 名称 ≤ 数值 单位` | `1 km 处定位精度 ≤10 m` |
| 相对指标 | `较 <基线全名> 降低/提高 ≥N%` | `通信资源占用：较固定 50:50 时频划分降低 ≥10%` |
| 时间类 | `≤ 数值（层级；规模；计时口径）` | `调度决策时间：≤100 ms（快变层单次求解；慢变层秒级更新；≤8 站；自感知数据就绪起计）` |
| 成对约束 | `A ≤ x（与 B 成对约束，其门限待 XX 给定）` | `虚警率 ≤5%（系统/告警级口径；与检测概率成对约束，其门限待任务书给定）` |

## 3. 必须写全的四件事

1. **基线**：相对指标不给基线＝无法考核。基线要写**全名 + 关键配置**
   （如"集中式全局求解（全量 CSI 与决策变量汇聚/广播）"）。
2. **限定条件**：`（组网模式）`、`（单站/多站）`、`（系统/告警级口径）`、`（置信度 X%）`——
   少一个限定，指标就变成"单站也要 ≥10 km"这类做不到的承诺。
3. **测量/统计口径**：时间类写"从什么到什么"；比例类写"按什么统计"（如"按感知占用的时频资源比例统计"）。
4. **考核归属**：本部分承接但不负责的项，写 `支撑的系统级指标（由项目集成与硬件环节考核）：…`，
   明确**不是本部分许下的诺**。

## 4. 「不画大饼」条款

| 情形 | 处理 |
| --- | --- |
| 指标值有出处（指南/任务书/上级） | 照写，并注明限定 |
| 指标值来自内部推算 | 写"〔推算〕"或直接给区间，并注明待实测确认 |
| 指标依赖未落实的条件（硬件、同步、许可、数据） | 要么补限定，要么在正文写清依赖方与时间，**不要只写在图上** |
| 指标本身有实现风险 | 在台账写明"须在第一阶段仿真后以统一算力平台实测确认；如需调整须经 XX 书面同意"，**不写"可删除"**（考核指标具合同属性） |
| 参数未定（门限、置信度、折算系数） | 写"待 XX 给定"，**不填猜的数** |

反面示例（都会在验收时被追着问）：
- `↓≥10%`（没基线、非规范记法）
- `定位精度 ≤10 m`（没距离限定＝承诺全距段）
- `≥10 km`（没写"（组网模式）"＝承诺单站）
- `虚警率 ≤5%`（没写成对约束＝门限可被抬高伪满足）
- `≤100 ms`（没层级、没规模、没计时口径）
- 图上写"最优/保证/彻底解决"，而正文自认 NP-hard、启发式、局部最优

## 5. 图↔文↔方案三方一致性

画完图后逐条比对三处（图内文字、正文对应段、技术方案/底稿）：

| 检查项 | 判定标准 |
| --- | --- |
| 指标数值 | 三处逐字一致 |
| 指标名与限定条件 | 三处逐字一致 |
| 术语与称谓 | 三处逐字一致 |
| 基线名称与配置 | 三处一致，且与台账一致 |
| 交付物名称与数量 | 三处一致（软件 1 套 / 报告 N 份） |
| 方法主张 | 图上的措辞不超过底稿与正文的主张强度 |

不一致时**以正文/台账为准**改图；若正文与方案冲突，先停下来人工确认——**不要两边各改一半**。
